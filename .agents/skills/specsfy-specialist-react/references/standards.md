# Padrões e referências React

## Modelagem

- Estado local para interação local; servidor continua owner de dados remotos.
- Reducer quando eventos e transições formam uma máquina compreensível.
- Context para dependência transversal estável, não como store universal.
- Error boundaries e Suspense somente nos boundaries que podem recuperar.
