# Padrões e referências shadcn/ui

## Padrões de sistema

- Shell: Sidebar + header + main landmark; navegação atual identificável.
- Dashboard: resumo → tendência → detalhe; período e filtros visíveis.
- Data table: título, filtros, ordenação, paginação, seleção, empty e error.
- Form: label, ajuda, erro, pending, confirmação e preservação após falha.
- Overlay: trigger semântico, título, descrição, foco inicial e retorno.
- Chart: título, unidade, período, legenda, tabela/descrição equivalente.
