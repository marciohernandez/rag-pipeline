# Ofertas

A base de exemplo reúne um catálogo fictício de ofertas de banda larga usado
para demonstrar o pipeline de ingestão e indexação sem depender de dados
reais de cliente.

## Plano Essencial

Velocidade de 100 Mbps, indicado para uso doméstico com poucos dispositivos
conectados simultaneamente.

## Plano Turbo

Velocidade de 500 Mbps, indicado para famílias com múltiplos dispositivos e
uso simultâneo de streaming e videoconferência.
